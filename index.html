英語リスニング練習

英語の物語を、声で聞きます。1文ごとに、「わかった / わからない」を、答えます。
このアプリについて
  • 練習の記録は、この端末の中(ブラウザの保存場所)にだけ、保存します。作者には、届きません。「同期」を設定すると、あなたの GitHub の、非公開リポジトリにも、保存します。
  • 読み上げは、端末の音声合成の声です。声や、答えを、どこにも、送りません。公開の置き場所(GitHub Pages)の、アクセスの記録(IP アドレスなど)は、GitHub 側に、残ることがあります。
  • 声は、端末によって、違います。音が出ない時は、音量と、マナーモード(消音)を、確かめてください。iPhone は、画面を触るまで、声が、鳴りません。
  • iPhone では、Safari で開いた時と、ホーム画面から開いた時で、記録の保存場所が、別です。どちらか一方で、使い続けてください(同期を使えば、そろえられます)。
  • 物語は、自作の 9 本と、VOA Learning English「The Open Boat」です(出典は、その物語の画面に、出ます)。

同期
練習の記録を、あなたの GitHub の、非公開リポジトリに、同期します(PC と iPhone で、記録が、そろいます)。練習中は、通信しません。同期に失敗しても、この端末の記録は、消えません。
合鍵(アクセストークン)は、この端末の中だけに、保存します。送り先は、GitHub だけです。そのリポジトリだけの、読み書き(Contents)の権限で、期限つきの合鍵を、作ってください。
