# 英語リスニング練習(Web 版)

英語の物語を、**声で聞いて**、1文ごとに、「わかった / わからない」を、答える、練習用の Web アプリです。「わからない」を押すと、英文・日本語訳・解説が出ます。個人用の練習アプリを、スマートフォン(iPhone など)でも、使えるようにした物です。

- 物語は、10本です(3つの難しさ × 3本の自作の物語と、VOA Learning English の「The Open Boat」)。英語の声は、**全部の文を、録音**してあります(489文)。
- 読む速さは、0.5 / 0.8 / 1.0 / 1.2 / 1.5倍から、選べます。
- 1回の練習は、1つの節(5文ほど)です。物語の最後まで聞くと、次の物語へ、続きます。

## 使い方

1. 公開のアドレスを開きます(iPhone なら、Safari か Chrome)。
2. 右の列(スマートフォンでは、下)で、物語の節を選びます。
3. 「聞き始める」→「スタート」を押すと、1文目が、読まれます。
4. 「わかった」か「わからない」を、押します。
- iPhone は、画面を触るまで、声が、鳴りません。
- ホーム画面に追加すると、アプリのように、開けます(オフラインでも、開けます)。

## 記録とプライバシー

- **練習の記録は、この端末の中(ブラウザの保存場所)にだけ**、保存されます。作者に、届きません。
- 声は、あらかじめ**録音した音声ファイル**です(1文 = 1ファイル)。音声が無い文や、再生できない時は、端末の音声合成を、使います。声や、答えを、どこにも、送りません。
- 公開の置き場所(GitHub Pages)の、アクセスの記録(IP アドレスなど)は、GitHub 側に、残ることがあります。
- **iPhone では、Safari で開いた時と、ホーム画面から開いた時で、記録の保存場所が、別**です。どちらか一方で、使い続けてください。
- 検索には、出ないように、しています(`noindex`)。ただし、これは、お願いであり、保証では、ありません。

### 記録の同期(任意)

表紙の「同期」の欄に、あなたの **GitHub の非公開リポジトリ**と、**アクセストークン**を入れると、複数の端末(PC と iPhone など)で、記録を、そろえられます。

- 練習の記録(`progress.json`)を、そのリポジトリに、書きます。練習中は、通信しません。
- どちらかで、上書きは、しません。履歴は、足し合わせ、節ごとの結果は、新しい日付、位置と速さは、更新の新しい方を、使います。
- トークンは、**その端末の中だけ**に、保存します。送り先は、`api.github.com` だけです(画面の `Content-Security-Policy` で、他のサイトへの通信は、ふさぎます)。
- トークンは、**そのリポジトリだけ**、**Contents: Read and write**、**期限つき**で、作ってください(GitHub の Settings → Developer settings → Fine-grained tokens)。
- 同期を、使わなくても、アプリは、使えます。

## 物語と出典

- 自作の物語: 「Ken and the Mountain」「The Red Umbrella」「Sara's Little Bakery」(それぞれ、3つの難しさ)。日本語訳と解説は、作者が、付けました。
- VOA Learning English「The Open Boat」(原作 Stephen Crane): 出典は、その物語の画面に、表示します。
- 録音の声: オフラインで動く AI の声 **Piper** の英語の声 `en_US-joe-medium`(ライセンス: CC0)で、作者が、自分の PC で、作りました。Piper は、作った音声の権利について、「よく決まっていない」と、書いています。

## 確かめたこと / 確かめていないこと

- 確かめた: Windows の Edge(自動試験。声は、偽物に、差し替えています)。計算・同期(偽の GitHub を使用)・画面の流れの、試験が、あります(`node logic_test.mjs`、`node sync_test.mjs`、`node app_smoke_test.mjs`)。
- **確かめていない**: iPhone の実機での、録音した音声の再生と、画面。本物の GitHub への同期。
- 声は、AI の声で、人の声では、ありません。録音が、使えない時の、読み上げは、端末によって、声が、違います。
- 「約○秒」は、単語数からの、目安です。

## 作り方

個人用の練習アプリから、`make_web.mjs` で、このフォルダの内容を、自動で、作っています(このフォルダを、直接、直すのでは、ありません)。
